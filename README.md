# Tern OMP Monitor Plugin

Tern terminal plugin for monitoring OMP (One Model Protocol) agent runs, pane statuses, and subagent lifecycles in real time.

## Features

- Real-time display of running agents across terminal panes.
- Status filters: All, Working, Waiting, Idle.
- One-click jump to agent terminal pane.
- Responsive styling (`style.css`) with Tern theme integration.

## Installation

```bash
mkdir -p ~/.config/tern/plugins
git clone https://github.com/wangm23456/tern-plugin-omp-monitor.git ~/.config/tern/plugins/omp-monitor
```

In Tern command palette: `OMP 状态监控` to open the monitor panel.
